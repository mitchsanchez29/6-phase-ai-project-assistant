# Phase Definitions

This directory contains the definitions and operating rules for the six phases of the 6-Phase AI Project Assistant.

Each phase defines:

* Purpose
* Inputs
* AI responsibilities
* Process
* Outputs
* Required artifacts
* Phase gate
* Handoff requirements
* Completion criteria

## Six Phases

1. THINK — Define and understand the project
2. DESIGN — Create the project blueprint
3. BUILD — Implement the approved design
4. VALIDATE — Test and verify the product
5. LAUNCH — Deploy and prepare for use
6. IMPROVE — Learn, iterate, and maintain

Phase definitions will be expanded into individual specification files as the framework develops.
